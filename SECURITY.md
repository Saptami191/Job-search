# Security Policy

## Supported versions

The latest release on the default branch is the supported version.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting feature for this repository after it is created.
If private reporting is unavailable, contact the repository maintainers through
GitHub and include only the information needed to reproduce the issue.

Do not include API keys, passwords, cookies, personal profiles, or other
Sensitive data in a report.

## Scope

Never commit credentials, browser sessions, candidate profiles, job history,
application dossiers, or generated reports. Source connectors must respect
service terms, API policies, rate limits, privacy obligations, and access
restrictions. This project does not bypass authentication or CAPTCHAs and does
not submit applications automatically.
